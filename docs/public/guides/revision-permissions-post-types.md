# How to Customize Permissions for Revisions

[PublishPress Revisions](https://publishpress.com/links/revisions) allow you to customize who can create and edit revisions. In this guide, we’ll show you how to customize permissions for user roles. We will decide the permissions for users roles in each post type.

- Install the [PublishPress Capabilities](https://publishpress.com/capabilities/) plugin.
- Go to the “Capabilities” screen.
- In the top-left corner, choose the role you want to edit under “Select Role to View/Edit”.
- Look in the center of the screen for the “Editing” area.

![Customize Permissions for Revisions](https://docs-media.publishpress.com/publishpress-revisions/editing-capabilities-aa460e0da3.webp)

Here’s how to use these permissions:

- **Publish**: if this box is checked, users can make their changes live without moderation.
- **Edit Published**: if this box is checked, users can edit published content and create revisions.

Let’s see an example of how that works. Imagine that we want a role that can create revisions, but not publish them. This next screenshot shows how to create a user role whose revisions must be approved by a higher-level user.

![Customize Permissions for Revisions](https://docs-media.publishpress.com/publishpress-revisions/create-revisions-573b7b9ae0.webp)

- **Edit**: Checked
- **Edit Others**: Checked
- **Publish**: Blocked
- **Edit Published**: Checked
