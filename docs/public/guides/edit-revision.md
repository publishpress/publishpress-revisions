# How to Edit New Revisions

With the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin, you can safely update any existing post. You can make a copy of the post, edit it, and then replace the original post.

This guide will show you how that process works.

- Go “[New Revisions](https://publishpress.com/links/new-revisions)” in WordPress admin menu.
- Click the “Edit” link under a revision:

![Edit link for Revisions](https://docs-media.publishpress.com/publishpress-revisions/edit-revision-link-7281c7e538.webp)

*Edit [Revision Queue](https://publishpress.com/links/links/revision-queue)*

- You can now make changes to your revision. Whenever you are ready to save changes, click the “Save Draft” button.
- None of the changes you save will go live on the site until you click an “Submit” or “Schedule” button. This is a safe space to work on updating your content.

![Edit Revision buttons](https://docs-media.publishpress.com/publishpress-revisions/edit-revisions-buttons-6a309b1997.webp)
