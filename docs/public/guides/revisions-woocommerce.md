# PublishPress Revisions Support for WooCommerce (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

[WooCommerce](https://wordpress.org/plugins/woocommerce/) is the most popular way to build a WordPress eCommerce site. With the Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions) you can submit, moderate, approve and schedule revisions to your WooCommerce products.

- When you are on the “Products” screen, click the “New Revision” link.

![New WooCommerce Revision](https://docs-media.publishpress.com/publishpress-revisions/new-wc-revision-3aa56a8e84.webp)

*New Wc Revision*

- Inside the product revision, the PublishPress buttons will appear in the top-right corner. These buttons are:  Update Revision Preview  Submit Revision Compare

![WooCommerce Revisions buttons](https://docs-media.publishpress.com/publishpress-revisions/woocommerce-revisions-buttons-51e6860983.webp)

*Revision Wc*

- Before you publish the updated copy of the product, your product revision will appear on the main “[Revision Queue](https://publishpress.com/links/links/revision-queue)” screen:

![Revision Queue for WooCommerce products](https://docs-media.publishpress.com/publishpress-revisions/woocommerce-product-revision-queue-7a8c46b624.webp)

All key WooCommerce fields are supported by [PublishPress Revisions](https://publishpress.com/links/revisions) Pro, including those in “Inventory”, Shipping”, “Linked Products”, “Attributes”, and “Advanced”. This feature also support Product Variations.

![WooCommerce product fields](https://docs-media.publishpress.com/publishpress-revisions/wc-fields-dd595ea721.webp)

If you are using 3rd party WooCommerce plugins, we do recommend testing their compatibility with WordPress revisions and PublishPress Revisions Pro.
