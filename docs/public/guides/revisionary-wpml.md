# PublishPress Revisions Support for WPML (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

The Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions) has support for [the WPML plugin](https://wpml.org/). For example, you can create revisions for a post in English and create separate revisions for the Spanish translation of that post.

- Go to your “Posts” screen.
- Click “[New Revisions](https://publishpress.com/links/new-revisions)” and you can create a translated version of your content in any language. Here’s the English version of a blog post:
