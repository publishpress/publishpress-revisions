# PublishPress Revisions Support for Divi (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

Divi is one of the most popular page-builders in WordPress, and it does integrate with the Pro version of [PublishPress Revisions](https://publishpress.com/revisions/).

Using [PublishPress Revisions](https://publishpress.com/links/revisions), it is possible for users to edit a page with Divi and submit an update for approval.

This workflow will apply to [anyone with the correct permissions](https://publishpress.com/knowledge-base/permissions-revisions/) to submit revisions.

- This image below shows what a users see when they create a revision for a post that uses Divi. They will see a “New Revision” link:

![Divi Builder](https://docs-media.publishpress.com/publishpress-revisions/divi-builder-3836a20e36.webp)

*Divi Builder*

- This next image shows what a site administrator will see when they go to edit revision created in Divi. They will see the normal editing layout in Divi, with the [PublishPress Revisions](https://publishpress.com/links/revisions) buttons in the top toolbar and right sidebar.
- Click “Edit With The Divi Builder” to make content changes.
- Click “Immediately” in the right sidebar to schedule future content changes.
