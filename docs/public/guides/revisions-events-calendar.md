# PublishPress Revisions Support for The Events Calendar (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

[The Events Calendar](https://wordpress.org/plugins/the-events-calendar/) plugin is one the most popular ways to create and list events in WordPress.

The Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions) and The Events Calendar work together successfully. Using these plugins together, it is possible to safely create a copy of published events, make changes, and then publish your changes.

- Make sure you are using the Gutenberg option for creating events.
- After installing [PublishPress Revisions](https://publishpress.com/links/revisions) Pro, you will be able to submit revisions to events using the “New Revision” option on the main “Events” screen.

![Events Revision](https://docs-media.publishpress.com/publishpress-revisions/events-revision-10e1f69c3b.webp)

*Events Revision*

- You will see the normal Event screen, but with additional PublishPress Revisions button in the top-right corner:

![Events Revision Options](https://docs-media.publishpress.com/publishpress-revisions/events-revision-options-2edd155f86.webp)

*Events Revision Options*

- Your event revisions will appear in the “[Revision Queue](https://publishpress.com/links/links/revision-queue)“.

![](https://docs-media.publishpress.com/publishpress-revisions/events-calendar-revision-queue-9e715f8243.webp)

PublishPress Revisions Pro will record changes to all your event fields and settings.

![](https://docs-media.publishpress.com/publishpress-revisions/date-field-revision-16a3f513f7.webp)
