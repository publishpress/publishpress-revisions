# PublishPress Revisions Support for Custom Post Type UI (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

[Custom Post Type UI](https://wordpress.org/plugins/custom-post-type-ui/) is a plugin provides an easy-to-use interface for registering and managing custom post types and taxonomies for your website.

With the Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions) you can submit, moderate, approve and schedule revisions to your Custom Post Type UI content.

When you edit a published item created with Custom Post Type UI, you can use the “[New Revisions](https://publishpress.com/links/new-revisions)” link:

![Revision Queue Links](https://docs-media.publishpress.com/publishpress-revisions/revision-queue-links-7beecd0ed7.webp)

*[Revision Queue](https://publishpress.com/links/links/revision-queue) Links*

Your post revision will appear on the main [Revision Queue](https://publishpress.com/links/links/revision-queue) screen:

![](https://docs-media.publishpress.com/publishpress-revisions/custom-post-type-revision-queue-1b449c106a.webp)

[PublishPress Revisions](https://publishpress.com/links/revisions) Pro supports all the core WordPress features. So if you add Categories, Tags, Excerpts or other features to your custom post type, they will be supported when you create revisions.
