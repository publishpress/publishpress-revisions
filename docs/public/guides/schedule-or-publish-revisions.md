# How to Moderate and Publish Revisions

[PublishPress Revisions](https://publishpress.com/links/revisions) enables users to safely make changes to published content. [PublishPress Revisions](https://publishpress.com/links/revisions) offers a safe space for users to work on content updates. When the changes are ready, they can ask for approval to publish the update. Administrators can approve or reject the changes. They can also schedule them to go live in the future.

This “[New Revisions](https://publishpress.com/links/new-revisions)” screen shows you the revisions that have been submitted. You can see posts in various statuses:

- **Not Submitted**: Users are still working on these updates.
- **Submitted**: These updates are waiting for approval.
- **Scheduled**: These changes are waiting to go live on a future date.

![posts in various statuses](https://docs-media.publishpress.com/publishpress-revisions/new-revisions-types-57ac26de1d.webp)

*All [Revision Queue](https://publishpress.com/links/links/revision-queue)*

If a user has sufficient permissions, they will see the “Preview” link for a revision.

![Preview Revision link](https://docs-media.publishpress.com/publishpress-revisions/preview-revision-af09be747b.webp)

*[Revision Queue](https://publishpress.com/links/links/revision-queue) Links*

They will be taken to the front of your site and you will see a toolbar across the screen. This will have several options. These are the options for a pending revision:

- **View Queue**: Go back to the [New Revisions](https://publishpress.com/links/new-revisions) screen.
- **Compare:** See the differences between this version and the currently published revision.
- **View Published Post**: See the currently published post.
- **Edit**: Make changes to this revision.
- **Approve**: Make this the currently published version of the content.
- **Decline**: This will move the revision back to “Unsubmitted” status.
- **Delete**: This will remove the revision and can not be undone.
