# PublishPress Revisions Support for Advanced Custom Fields (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

The Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions) has support for [the Advanced Custom Fields (ACF) plugin](https://wordpress.org/plugins/advanced-custom-fields/). You can schedule, moderate and approve revisions for content that uses ACF.

This feature supports almost all ACF fields in both the Free and Pro version. These fields include these: Text, Text Area, Number, Range, Email, URL, Image, Taxonomy, True/False, Gallery, Repeater, and many more.

- To create a revision for post that use ACF, click on the “New Revision” link.

![New Revision Link](https://docs-media.publishpress.com/publishpress-revisions/new-revision-link-9133f3f5a8.webp)

*New Revision Link*

- Go to the “[Revision Queue](https://publishpress.com/links/links/revision-queue)“.
- Click “Edit” and you can update the revision, including the ACF fields.
- Click “Compare” and you can see what’s changed in this revision:

![Revision Queue with ACF Fields](https://docs-media.publishpress.com/publishpress-revisions/acf-field-compare-link-0cf6b1bf11.webp)

The “Compare” screen will show you any changes that have happened with ACF Fields. In this example, we changed the content in two ACF fields from “Before” to “After”.

![ACF Fields in PublishPress Revisions](https://docs-media.publishpress.com/publishpress-revisions/acf-field-compare-02e5040df4.webp)

If you have more advanced field such as Google Maps, Gallery, or Repeater, those fields will appear with text or numerical values. For example, in the screenshot below, the Gallery field contains an image with an ID of 47. That is what is stored in the database, and that is what will appear in the “Compare” screen.

![Advanced Revisions with ACF](https://docs-media.publishpress.com/publishpress-revisions/acf-revision-advanced-1634b53850.webp)
