# Email Notifications for Revisions (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

The Pro version of the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin allows you to send email notifications. You can sent notifications for actions such as submitting a new revision, or publishing a scheduled revision.

These notifications require the [PublishPress Planner](https://publishpress.com/links/planner) plugin which has [a notification system](https://publishpress.com/knowledge-base/start-planner-notifications/).

- Install [PublishPress Revisions](https://publishpress.com/links/revisions) Pro, plus also the [PublishPress Planner](https://publishpress.com/links/planner) plugin.
- Go to “Planner” and then “Notifications” in the WordPress admin menu. You will now see a list of emails that are ready to customize.

![Planner notifications with Revisions](https://docs-media.publishpress.com/publishpress-revisions/revisions-notifications-1e7a4fa4dd.webp)

Inside each notification, you can check the “Previous statuses” and “New status” options. You can select Revisions statuses in these areas and these can be used to trigger your notifications.

![Planner and Revisions notifications](https://docs-media.publishpress.com/publishpress-revisions/planner-revisions-3e8f7f594a.webp)
