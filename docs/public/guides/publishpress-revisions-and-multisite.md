# PublishPress Revisions and Multisite Networks

The [PublishPress Revisions](https://publishpress.com/links/revisions) plugin has support for WordPress multisite networks. It is possible to configure some settings so that they are shared across the network.

- Install and enable the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin.
- Go to your main network site. This will be marked by the word “Main” on your “Sites” screen.

![](https://docs-media.publishpress.com/publishpress-revisions/main-site-c4e8db264a.webp)

Look for the “Revisions” link on your main site. You will see two special links, “Network Settings” and “Network Defaults”.

![](https://docs-media.publishpress.com/publishpress-revisions/multisite-menu-revisions-1570ee0e66.webp)

The main screen for multisite is “Network Settings”. You use this tab to make network-wide changes to PublishPress Revisions settings.

![](https://docs-media.publishpress.com/publishpress-revisions/network-settings-9405f117cb.webp)

Under the “Setting Scope” tab, you can choose which settings to control network-wide. If you uncheck any of these boxes, the settings can then be controlled separately on each site.

![](https://docs-media.publishpress.com/publishpress-revisions/setting-scope-b2fa42a50b.webp)
