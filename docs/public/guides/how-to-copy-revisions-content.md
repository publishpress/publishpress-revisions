# How to Copy Revisions Content

By default, it is not possible to copy the content of a revision in WordPress. The [PublishPress Revisions](https://publishpress.com/links/revisions) plugin solves this problem by providing a “Copy” button.

This screenshot below illustrates the limitations of the default WordPress approach to revisions. When you try to select the content for either the previous or the new content, you will be forced to select the content from both areas together.

![Copy Revisions content](https://docs-media.publishpress.com/publishpress-revisions/copy-revisions-content-e2828dced9.webp)

The [PublishPress Revisions](https://publishpress.com/links/revisions) plugin solved this limitation by providing a “Copy” button for the content in each column. Click this button and the content of the previous or the new content will be saved to your clipboard.

![Copy the Revisions content](https://docs-media.publishpress.com/publishpress-revisions/revisions-plugin-copy-a16ea792c4.webp)
