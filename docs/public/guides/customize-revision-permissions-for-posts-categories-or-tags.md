# Customize Revision Permissions for Posts, Categories, or Tags (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

When using the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin, it is also possible to customize the ability to create revisions for specific Posts, Categories, or Tags. This can be done with the addition of the [PublishPress Permissions Pro](https://publishpress.com/permissions/) plugin.

You will able to customize permissions using the “Revision Exceptions” box under each post, page, category or tag. In the image below, you can choose three ways to customize permissions:

- Roles
- Groups
- Users

![](https://docs-media.publishpress.com/publishpress-revisions/revision-exceptions-3e442d767e.webp)

In the image below, only the “Author” role and the “Editor” role are able to create revisions:

![](https://docs-media.publishpress.com/publishpress-revisions/revisions-permissions-c209adf87e.webp)
