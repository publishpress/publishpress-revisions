# Getting Started with Past Revisions

Table of Contents

- [The Past Revisions Screen](#0-toc-title)
- [Actions on the Past Revisions Screen](#h-actions-on-the-revision-archive-screen)

This is a guide to the “Past Revisions” feature in the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin.

The “Past Revisions” screen shows all the content revisions on your site. This includes a history of all the changes to your content.

Normally it’s really difficult to view these changes in WordPress. The only way to access them is via a small “Revisions” link inside each individual post. Our “Past Revisions” screen solves this problem. The “Past Revisions” screen displays all the changes on one screen and allows you to search, filter, and manage the revisions.

## The Past Revisions Screen [#](#0-toc-title)

In the screenshot below, you can see the “Past Revisions” feature. The most recently created revision is on the top of this list.

![Past Revisions scree](https://docs-media.publishpress.com/publishpress-revisions/past-revisions-screen-e0e3a85c0c.webp)

On the “Past Revisions” screen, you’ll be able to see information about each revision, including the following:

- **Revision**: The title of the post.
- **Count**: How many revisions this post has.
- **Post Type**: The post type for the post that has the revision.
- **Revised**: Who created the revision.
- **Revision Date**: When the revision was created.
- **Action**: Was this a normal revision, or did it use the [PublishPress Revisions](https://publishpress.com/links/revisions) feature that allows you to [approve or schedule revisions](https://publishpress.com/knowledge-base/revisions-start/).
- **Published Date**: The publication date shown on the post.
- **Published Authors**: The author shown on the post.

## Actions on the Past Revisions Screen [#](#h-actions-on-the-revision-archive-screen)

There are several different actions you can take on the “Past Revisions” screen. Underneath each post title, you’ll see a “Compare”, “Preview”, and a “Filter” link.

![Action links in the Revision Archive feature](https://docs-media.publishpress.com/publishpress-revisions/compare-preview-filter-a9f9507b01.webp)

If you click on the “Compare” link, you’ll be able to see the normal WordPress revisions screen for this post. You can see the old content marked in red and the new content highlighted in green.

![Comparing revisions in WordPress](https://docs-media.publishpress.com/publishpress-revisions/compare-revisions-9787edbfed.webp)

If you click on the “Preview” link, you’ll be taken to the frontend of the site. There will be a bar across the top of the site and this allows you to take actions on this revision.

![Past Revisions toolbar](https://docs-media.publishpress.com/publishpress-revisions/past-revision-toolbar-3545481892.webp)
