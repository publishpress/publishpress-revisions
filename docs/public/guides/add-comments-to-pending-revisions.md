# Add Comments to Unpublished Revisions

[PublishPress Revisions](https://publishpress.com/links/revisions) allows you to submit revisions for published content. If you want to discuss these revisions, you can do this using [the PublishPress plugin](https://publishpress.com/calendar/).

- Install the PublishPress Calendar and [PublishPress Revisions](https://publishpress.com/links/revisions) plugins.
- Go to PublishPress > Notifications.
- Create or edit a notification for the “[Editorial Comments](https://publishpress.com/knowledge-base/editorial-comments/)” feature.
- Under “When to notify?”, choose “When an editorial comment is added”.
- Under “Post type”, choose your post types. There is not a separate option for revisions.
- Save this notification.

![](https://docs-media.publishpress.com/publishpress-revisions/notifications-revisions-2548033908.webp)

- Go to the “Revisions” link in the WordPress admin menu.
- Click “Edit” next to a revision.
- Scroll down and you will see an “Editorial Comments” box. Here you can leave editorial comments for this revision.

![](https://docs-media.publishpress.com/publishpress-revisions/editorial-comment-revision-8f4ef08db2.webp)

You will receive notifications for revisions. These notifications will be almost exactly the same for normal WordPress content:

![](https://docs-media.publishpress.com/publishpress-revisions/revision-comment-email-084de10f20.webp)
