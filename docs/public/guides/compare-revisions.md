# How to Compare Revisions

When you’re deciding whether or not to approve a pending revision, you can compare the new version side-by-side with the old.

Here’s how to use the Compare feature in [PublishPress Revisions](https://publishpress.com/revisions/):

- Go to the “[New Revisions](https://publishpress.com/links/new-revisions)” or “[Past Revisions](https://publishpress.com/links/past-revisions)” links in your WordPress admin menu.
- Look for the “Compare” link under a revision.

![Compare link for revisions](https://docs-media.publishpress.com/publishpress-revisions/compare-link-31beb51f4d.webp)

You will now see the differences between the new version and the currently published revision. This image below shows an example of what you will see. The current version is marked in red and the new version is marked in green.

![](https://docs-media.publishpress.com/publishpress-revisions/compare-revisions-ed4c98eb08.webp)
