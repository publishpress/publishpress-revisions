# Submit Revisions for Unpublished Posts (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

With [PublishPress Revisions](https://publishpress.com/links/revisions) Pro, you can create revisions for unpublished WordPress posts.

So if you have a post in “Draft” or “Pending Review” status, you can submit a revision of that content for approval.

- Go to “Revisions > Settings > [New Revisions](https://publishpress.com/links/new-revisions) > Submission.
- Check the box for “Revision Submission for Unpublished Posts”
