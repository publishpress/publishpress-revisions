# Getting Started with PublishPress Revisions

This is a guide to help you start using the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin.

The are two main features in this plugin.

First, the [New Revisions](https://publishpress.com/knowledge-base/revision-queue/) feature allows you to safely make changes to published content. The original content will live while you work on the changes. This feature offers a safe space for users to work on content updates. When the changes are ready, they can ask for approval to publish the update. Administrators can approve or reject the changes. They can also schedule them to go live in the future. You can see the [New Revisions](https://publishpress.com/links/new-revisions) feature in the screenshot below.

![New Revisions Feature](https://docs-media.publishpress.com/publishpress-revisions/new-revisions-screen-9189426bb8.webp)

Second, the [Past Revisions](https://publishpress.com/knowledge-base/revision-archive/) feature enables you to view all the previous revisions on your WordPress site. You can see the [Past Revisions](https://publishpress.com/links/past-revisions) feature in the screenshot below.

![Past Revisions feature](https://docs-media.publishpress.com/publishpress-revisions/past-revisions-screen-8d568e50a6.webp)
