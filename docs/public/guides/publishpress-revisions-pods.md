# PublishPress Revisions Support for PODS (Pro)

[The PODS Framework](https://wordpress.org/plugins/pods/) is an excellent way to create custom post types in WordPress. With the Pro version of [PublishPress Revisions](https://publishpress.com/links/revisions), you can submit, moderate, approve and schedule revisions to your PODS content.

To see how this integration works, you will need to create or modify a post type using PODs:

![](https://docs-media.publishpress.com/publishpress-revisions/sample-pod-5bb104bc7a.webp)

When you see published POD item on the “Posts” screen, you can use the “New Revision” option.

![New Revision Link](https://docs-media.publishpress.com/publishpress-revisions/new-revision-link-9133f3f5a8.webp)

*New Revision Link*

Your PODs revision will appear on the main [Revision Queue](https://publishpress.com/links/links/revision-queue) screen:

![](https://docs-media.publishpress.com/publishpress-revisions/pods-revision-queue-3eb6074029.webp)

All PODS fields are supported by [PublishPress Revisions](https://publishpress.com/links/revisions) Pro, including Text, Image, Date and more.

![](https://docs-media.publishpress.com/publishpress-revisions/penguin-revision-95aff3dc98.webp)
