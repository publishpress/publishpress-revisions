# Getting Started with New Revisions

Table of Contents

- [How to Create New Revisions](#h-how-to-create-revisions)
- [How to View All New Revisions](#1-toc-title)

This is a guide to the “New Revisions” feature in the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin.

The “New Revisions” feature enables you to control changes to your published content.

The “New Revisions” feature allows users to safely make changes to content. It provides a safe space for users to work on content updates. When users have finished making changes, they can ask for your approval. This is a great way to collaborate and avoid mistakes. You can choose to publish the changes immediately, or schedule them to go live later.

## How to Create New Revisions [#](#h-how-to-create-revisions)

- Go to the “Posts” or “Pages” link in your WordPress admin menu.
- Find a post that is marked as “Published”.
- Hover over the post or page that you want to update, and click the “Create Revision” link.

![Create revisions link in PublishPress Revisions](https://docs-media.publishpress.com/publishpress-revisions/create-revision-link-1ec3d5e4c1.webp)

*New Revision Link*

- You will now see a new copy of your post.
- Make a change to this copy of the published post. The change can be as simple as adding some text.
- Check the “Submit” button if you want to send the post for approval. If you have enough permissions, you can click “Approve” to automatically make your changes live on the site.

![Submit Changes](https://docs-media.publishpress.com/publishpress-revisions/submit-changes-e7f0300c59.webp)

*Submit Changes*

- You’ll see a message that your revisions has been submitted. If you want, you can keep editing the revision. When you want to save new changes, click the purple “Update Revision” button.

## How to View All New Revisions [#](#1-toc-title)

- Click “Revisions” then “New Revisions” in the WordPress admin menu.
- You’ll be taken to the “New Revisions” screen. This is where all submitted revisions wait to be approved.

![New Revisions screen](https://docs-media.publishpress.com/publishpress-revisions/new-revisions-screen-9189426bb8.webp)

*Revision Queue 3*

- Underneath each revision, you can choose from several options: “Edit”, “Copy”, “Delete”, “Preview” and “Compare”.

![Revisions Buttons](https://docs-media.publishpress.com/publishpress-revisions/revisions-buttons-81bc02b66f.webp)

*Revisions Buttons*

If you click “Preview”, you will go the front of the site where you have several options.

- **View Queue**: You’ll go to the “New Revisions” screen.
- **Compare**: You’ll go to the screen that compares old and new versions of the content.
- **View Published Post**: You’ll see the version of this post that is currently live on the site.
- **Edit:** You can make more changes to the current revision.
- **Publish now**: You can make these new changes live on the site.

![Pubish Links](https://docs-media.publishpress.com/publishpress-revisions/pubish-links-46468cda06.webp)

*Publish Links*
