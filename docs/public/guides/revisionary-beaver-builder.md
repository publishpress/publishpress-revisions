# PublishPress Revisions Support for Beaver Builder (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

[PublishPress Revisions Pro](https://publishpress.com/revisions/) has support for [the Beaver Builder plugin](https://wordpress.org/plugins/beaver-builder-lite-version/). Here’s how to use [PublishPress Revisions](https://publishpress.com/links/revisions) Pro and Beaver Builder together:

- In your WordPress admin area, click “New Revision” for a post or page that uses Beaver Builder.

![New Revision Beaver](https://docs-media.publishpress.com/publishpress-revisions/new-revision-beaver-5932831f6b.webp)

*New Revision Beaver*

- On the next screen, you will be able to click “Launch Beaver Builder” and create a new version of this post.
- Click “Submit Revision” to submit your updates.

![Beaver Revision](https://docs-media.publishpress.com/publishpress-revisions/beaver-revision-86d4dc9fbe.webp)

*Beaver Revision*

- In the WordPress admin area, you can visit the “[Revision Queue](https://publishpress.com/links/links/revision-queue)” screen and you will see the submitted revision of your Beaver Builder page. It will be waiting for your approval.

![Beaver Builder Compare](https://docs-media.publishpress.com/publishpress-revisions/beaver-builder-compare-1ecc8b0bfd.webp)

*Beaver Builder Compare*

Beaver Builder doesn’t have a post date option in the frontend interface, so [PublishPress Revisions](https://publishpress.com/links/revisions) currently can not create [scheduled revisions](https://publishpress.com/links/scheduled-revisions) there.

However, it is possible to schedule revisions to Beaver Builder content via the WordPress admin area.

- When you’re editing a revision, click “Immediately”.
- Choose the date you want your post changes to go live.
- Click the “Submit Revision” button.

![Submit Beaver](https://docs-media.publishpress.com/publishpress-revisions/submit-beaver-7ec1808ded.webp)

*Submit Beaver*
