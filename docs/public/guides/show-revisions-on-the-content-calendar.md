# Show Revisions in PublishPress Planner

It’s possible to combine the [PublishPress Revisions](https://publishpress.com/links/revisions) and [PublishPress Planner](https://publishpress.com/links/planner) plugins.

In the Revisions plugin, you can [schedule revisions to be automatically published in the future](https://publishpress.com/knowledge-base/schedule-revision-future/). This allows you to update content now, but publish those changes at a later date.

In the Planner plugin, you can use [the Content Calendar screen](https://publishpress.com/knowledge-base/content-calendar/) to see all your planned content.

You can see all your [scheduled revisions](https://publishpress.com/links/scheduled-revisions) on the [Content Calendar](https://publishpress.com/links/content-calendar) screen. If you’re using the Pro version of [PublishPress Planner](https://publishpress.com/links/planner), you’ll see the “Show Revisions” button in the screenshot below.

![Show Revisions on Calendar](https://docs-media.publishpress.com/publishpress-revisions/show-revisions-76daf2a23c.webp)

After you click the “Show Revisions” button, you’ll be able to see all your [scheduled revisions](https://publishpress.com/links/scheduled-revisions), as in this screenshot below:

![Schedule revisions on Content Calendar](https://docs-media.publishpress.com/publishpress-revisions/revisions-calendar-59456b25b2.webp)

This approach also works for the [Content Overview](https://publishpress.com/knowledge-base/the-content-overview-screen/) and [Content Board](https://publishpress.com/knowledge-base/the-content-board-screen/) screens. This next screen shows how to view revisions on the [Content Overview](https://publishpress.com/links/content-overview) screen:

![Content Overview revisions](https://docs-media.publishpress.com/publishpress-revisions/content-overview-revisions-499eec1c71.webp)

This next screen shows how to view revisions on the [Content Board](https://publishpress.com/links/content-board) screen. If you click “Show Revisions”, only the revision statuses will be shown.

![Content Board Revisions](https://docs-media.publishpress.com/publishpress-revisions/revision-content-board-1f4b704789.webp)
