# A List of Some Plugins Supported by PublishPress Revisions

[PublishPress Revisions](https://publishpress.com/links/revisions) is built on top of the core WordPress feature called “revisions”.

A sizeable percentage of WordPress plugins do not support this WordPress feature, so will not work with [PublishPress Revisions](https://publishpress.com/links/revisions). [Click here for a more detailed overview of this topic](https://publishpress.com/knowledge-base/support-publishpress-revisions/).

If you want to find out whether a plugin works with PublishPress Revisions, please start by testing it with the core WordPress revisions system.

If you need help assessing whether a plugin works with PublishPress Revisions, please [contact us](https://publishpress.com/contact/).

This table is not a complete list of supported plugins. This table simply lists popular plugins that we have tested with PublishPress Revisions:
